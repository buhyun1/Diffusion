# t_discrete_tail 
Heavy-Tailed Diffusion Models (ICLR 2025) discrete 구현

|  |  |
|---|---|
| 날짜 | 2026-08-31 |
| 데이터 | FashionMNIST class 0 (T-shirt/top), 1000장 |
| 질문 | 노이징을 Gaussian 대신 Student-t로 바꾸면 생성 분포의 꼬리가 두꺼워지는가 |
| 결론 | **네 지표 모두 ν=3이 데이터에 더 가깝다** |

EDM 식이 아니라 논문의 discrete 수식을 그대로 구현해 실험했다.

## 1. 목표

노이징 과정을 Gaussian이 아닌 Student-t로 바꾸면 생성 분포의 **꼬리**가 실제로 두꺼워지는가.

- 유계 데이터(픽셀 [−1,1])에서 "꼬리"를 측정할 수 있는 **지표**가 필요하다.

## 2. 구현

스케줄로는 선형 보간 **µ_t = 1−t, σ_t = t** 를 채택했다. 경계조건(µ_0=1, σ_0=0, µ_T=0, σ_T=1)을 만족하는 가장 단순한 선택이다.

| 파일 | 역할 |
|---|---|
| `posterior.py` | 논문 Eq. 2 · 7 — perturbation kernel, prior, reverse posterior |
| `unet.py` | D_θ |
| `run.py` | 스케줄 · 학습 · 샘플링 · 명령행 진입점 |
| `embed.py` | 특징공간용 분류기 (`feat NN`, `FID`) |
| `analyze.py` | 지표 계산 · 반복 측정 · Welch t-검정 |

### 실행

```bash
python run.py embed
python run.py train   --nu 3.0   --epochs 100 --label 0 --limit 1000 --out results/nu3
python run.py train   --nu 100.0 --epochs 100 --label 0 --limit 1000 --out results/nu100
python run.py analyze --ckpt results/nu3/ckpt.pt results/nu100/ckpt.pt \
                      --label 0 --limit 1000 -n 1000 --corr 0.99 --steps 200 --repeat 10 --out results/stat
```

- 경로는 실행 위치 기준 상대경로다.
- 코드가 `download=False`로 되어 있어 FashionMNIST를 미리 `data/FashionMNIST/raw`에 두어야 한다 (`--data`로 변경 가능).
- 학습 시 t는 U[t_min, 1]에서 균등하게 뽑는다.

## 3. 구조적 발견

### 3.1 Student-t는 덧셈에 닫혀 있지 않다

DDPM은 순방향을 **한 스텝씩** 정의한다.

```
x_t = √(1−β)·x_{t−1} + √β·ε
```

이게 가능한 이유는 **가우시안이 덧셈에 닫혀 있기 때문**이다. 독립 가우시안을 아무리 더해도 가우시안이라, 200스텝을 누적한 q(x_t|x_0)이 다시 닫힌 형태의 가우시안으로 나온다.

Student-t는 그렇지 않다. 독립 t_ν를 n개 더해 √n으로 표준화하면 t_ν가 아니다.

### 3.2 reverse step은 사실상 Gaussian이다

논문은 사후분포의 자유도를 **ν+d**로 규정한다. 이미지에서는 d=784다. x_t의 784개 좌표를 관측하면 공유 κ가 사실상 확정되므로, 조건부 분포가 Gaussian에 수렴한다.

### 3.3 corr이 꼬리 반영률을 결정한다

σ²₁₂ = σ²₂₁ = corr·σ_t·σ_{t−Δt}로 두면 corr ∈ [−1,1]이 Σ의 PSD 허용 범위를 정확히 덮는다.

| corr | Σσ̄² | 특징 |
|---|---|---|
| 0.00 | 66.17 | x_t 계수 0 |
| 0.50 | 49.63 |  |
| 0.90 | 12.57 |  |
| 0.99 | 1.32 | 채택 (분산 반영) |
| 1.00 | 0.00 | σ̄=0, 결정론적 |

## 4. 이미지 실험

픽셀이 유계라 꼬리가 픽셀 값으로 나타날 수 없다. 그래서 "평범하지 않은 이미지가 더 자주 나오는가"로 조작적 정의를 바꿨다.

| 지표 | 공간 | 재는 것 |
|---|---|---|
| `pixel std` | 픽셀 | 생성 이미지 픽셀값의 표준편차 (명암 대비) |
| `NN dist top10` | 픽셀 | 학습 이미지까지의 거리, 상위 10개 평균 |
| `feat NN top10` | 분류기 특징 (128d) | 분류기 공간에서 상위 10개 평균 |
| `FID` | 분류기 특징 | 두 분포의 평균, 공분산 비교 |

## 5. 결과

**설정** — ν 외 모든 조건 동일. 학습 1000장, 100 epoch, corr 0.99, 200스텝, 생성 1000장, 반복 10회.
원자료는 [`results/stat/metrics.csv`](results/stat/metrics.csv)에 있다.

| 집합 | pixel std | NN dist top10 | feat NN top10 | FID |
|---|---|---|---|---|
| **data (기준)** | 0.701 ± 0.004 | 17.757 ± 0.732 | 5.686 ± 0.165 | 0.181 ± 0.016 |
| **ν = 3** | 0.724 ± 0.004 | 16.004 ± 0.481 | 4.522 ± 0.125 | 3.314 ± 0.046 |
| **ν = 100** | 0.742 ± 0.006 | 14.986 ± 0.473 | 4.415 ± 0.101 | 3.966 ± 0.114 |

### 데이터와의 거리 (작을수록 좋음)

| 지표 | ν=3 | ν=100 | 우세 |
|---|---|---|---|
| pixel std | **0.023** | 0.042 | ν=3 |
| NN dist top10 | **1.753** | 2.771 | ν=3 |
| feat NN top10 | **1.165** | 1.271 | ν=3 |
| FID | **3.133** | 3.785 | ν=3 |

**네 지표 모두 ν=3이 데이터에 더 가깝다.** 셋이 통계적으로 유의하고, 유의하지 않은 `feat NN top10`도 방향은 같다.

FID가 가장 강한 신호다(t = −15.94). 바닥값 0.181 대비 ν=100의 격차 3.785 중 **17.2%를 ν=3이 좁혔다**.
