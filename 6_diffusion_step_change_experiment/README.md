# diffusion_step_change_experiment 연구노트

## 1. 목적

class-conditional DDPM으로 소수 클래스 fake를 만들어 채우는 오버샘플링에서, diffusion의 스텝 수 T를 줄여도 분류 성능이 유지되는지 확인한다. 학습과 샘플링 모두 T=22, 30, 100, 300으로 바꿔 비교한다.

**이 실험에서는 diffusion의 학습 스텝과 샘플링 스텝이 동일하다.** T로 학습한 모델을 같은 T스텝으로 샘플링한다. T=1000으로 학습하고 샘플링 스텝만 줄이는 respacing 실험(`diffusion_image_filter/exp1_oversampling_step_10`)과는 다르다.

| 실험 | 폴더 | T |
|---|---|---|
| 1 | `exp_diffusion_step_22` | 22 |
| 2 | `exp_diffusion_step_30` | 30 |
| 3 | `exp_diffusion_step_100` | 100 |
| 4 | `exp_diffusion_step_300` | 300 |

## 2. 실험 설정

`diffusion_step_300/exp2_oversampling_step_300`(오버샘플링)과 같은 설정이고 T만 다르다.

**데이터**
- 3클래스: Normal(0), Underfill_50FR(1), Underfill_Fan(2). 64×64로 resize 후 [-1, 1]로 정규화.
- 불균형 train 800 / 80 / 80장, 균형 test 클래스당 100장.
- seed 0~9마다 train/test 분할을 새로 뽑는다 (샘플 단위 분할, `build_imbalanced_split`).
- 데이터 경로는 환경변수 `DATA_ROOT`로 지정한다. 기본값은 노트북 기준 상대경로 `../../data/256`이다.

**Diffusion**
- 조건부 U-Net(dim=32), Adam lr 2e-4, EMA decay 0.999, 700 epoch (1 epoch = 24 step).
- 학습 스텝과 샘플링 스텝이 동일하다 (학습 timesteps = 샘플링 스텝 = T). β 스케줄은 `GaussianDiffusion`이 1000/T를 곱해 T=1000과 스케일을 맞춘다.
- EMA 모델로 소수 클래스(1, 2)를 클래스당 720장(= 800 − 80)씩 생성해 fake 풀을 만든다.

**분류기**
- 작은 CNN, Adam lr 1e-3, batch 40, 50 epoch = 1200 step.
- 매 step 실제 배치의 Normal 수에 맞춰 부족한 소수 클래스를 풀에서 무작위로 꺼내 채운다.
