## 논문

**Heavy-Tailed Diffusion Models** (Pandey et al., ICLR 2025, [arXiv:2410.14171](https://arxiv.org/abs/2410.14171))

노이징 분포를 Gaussian 대신 Student-t로 바꿔 확산모형이 무거운 꼬리를 생성하도록 한다. 이 폴더는 논문의 식을 DDPM 스케줄 위에 1D로 구현해, 꼬리를 직접 잴 수 있는 데이터에서 검증한다.

| | 식 |
|---|---|
| 순방향 | `q(x_t \| x_0) = t_d(µ_t x_0, σ_t² I, ν)` — `κ ~ InvGamma(ν/2, ν/2)`, `x_t = µ_t x_0 + σ_t √κ ε` |
| 역방향 | `p(x_{t−1} \| x_t) = t_d(µ_θ, s_t · σ̄_t² I, ν + d)` |
| 조건부 스케일 | `s_t = (ν + δ_t) / (ν + d)`, `δ_t = ‖x_t − µ_t D‖² / σ_t²` |
| 손실 | `L = E‖D_θ(x_t, t) − x_0‖²` (논문 Eq. 10) |

- 스케줄: 선형 β DDPM (`µ_t = √ᾱ_t`, `σ_t² = 1 − ᾱ_t`), T = 1000, β 1e-4 → 0.02
- `s_t`를 빼면 매 스텝 독립 κ가 1000개 증분에서 평균되어 주변분포가 Gaussian이 된다.

## 2. 결과 분석 (2026-09-14)

**한 줄 결론** 도움이 안 된다.

1-D t(3) 데이터에서 Gaussian DDPM(ν=500)이 이미 거의 완벽하고, ν를 낮출수록 나빠진다.

원인은 heavy-tail 커널에서 denoiser가 전 구간 평평해진다는 점이다. 그 결과 꼬리 생성 책임이 학습 가능한 denoiser에서 잡음이 큰 `s_t` 추정으로 넘어간다.

### 2.1 배경과 가설

검증하려던 가설: **데이터가 heavy-tail이면 확산 잡음도 heavy-tail(Student-t)로 쓰는 것이 유리하다.**

### 2.2 주요 결과 — `2_net_vs_exact.ipynb`

- **net:** 신경망 출력을 x0 자리에 대입했다.
- **exact:** 실제 사후분포의 평균을 x0 자리에 대입했다.

1D에서는 사후평균을 정확히 계산할 수 있다. 그래서 학습 오차가 없는 경우 어떻게 샘플링되는지 비교했다.

```
E[x_0|x_t] = Σ_i w_i x_i,   w_i ∝ (1 + z_i²/ν)^(−(ν+1)/2),   z_i = (x_t − µ_t x_i) / σ_t
```

```

TRUE          |       -       -    3.00  1.000  3.00  10.21  1.530  0.0154
```

**ν가 클수록 좋다.** ν=500 exact는 KS 0.0129, P(|x|>5) 0.0171로 사실상 정확하다.

**1차원에서는 Gaussian DDPM이 t(3) 데이터를 이미 거의 완벽하게 재현한다.** 꼬리는 잡음이 아니라 denoiser/데이터에서 나온다.

### 2.3 출력 값 비교 — `3_s_t_trace.ipynb`, `4_step_sweep.ipynb`

다른 부분은 다 비슷하고, 차이는 조건부 스케일 `s_t = (ν + δ_t) / (ν + d)`에서 나타난다.

- **자유도 3:** 초반에는 `s_t`가 10까지 튀어오르는 구간이 있다. 하지만 t=1 시점으로 가면 1보다 낮은 값이 나와 노이즈를 줄이므로 다양성이 감소한다.
- **자유도 500:** `s_t`가 거의 일정하게 1이라 분산이 그대로 유지된다.

그래서 스텝 수를 줄이면 분포가 어떻게 되는지도 시각화했다 (`4_step_sweep.ipynb`). 그래도 Gaussian일 때 커버리지가 더 넓었다.
